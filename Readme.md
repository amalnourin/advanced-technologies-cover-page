# 🚀 Advanced Technologies Cover Page  

A modern, responsive **landing page** built with **HTML**, **CSS**, and **Bootstrap** during **NxtWave coding practice**.  
The design includes a **full-screen background image**, **Google Fonts**, and **custom-styled buttons**, showcasing clean and structured front-end development.

---

## ✨ Key Highlights
- 🌆 **Full-screen background** with `background-size: cover`.
- 🎨 **Custom buttons** – "Learn More" & "Save Draft".
- 🔠 **Google Fonts** for professional typography.
- 📱 **Responsive design** powered by Bootstrap classes.
- ⚡ **Clean codebase** for easy understanding and future expansion.

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **Bootstrap 4**  
- **Google Fonts**
