# 🚀 Advanced Technologies Cover Page

A simple and responsive landing page built with **HTML**, **CSS**, and **Bootstrap 4** during **NxtWave coding practice**.  
This project highlights a modern UI with a **full-screen background image**, **Google Fonts**, and **custom-styled action buttons**.

---

## Features

- Light/dark mode toggle
- Live previews
- Fullscreen mode
- Cross platform


---

## Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 4**
- **Google Fonts**
---

## How to run

1. Clone this repository:
   ```bash
   git clone https://github.com/amalnourin/advanced-technologies-cover-page.git
   ```
2. Open the `index.html` file in your browser.
